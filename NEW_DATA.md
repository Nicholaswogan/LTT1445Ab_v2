# Current data and grid assessment

The supported analysis uses the final DD12758 photometric-GP/RV-GP system fit.
See [JOINT_RETRIEVAL.md](JOINT_RETRIEVAL.md) for the adopted measurement,
likelihood, correlated priors, run commands, and output locations.

Run `python assess_new_data.py --sensitivity` in conda environment `ltt` to
regenerate `results/final_gp_v1/new_data_assessment.json`. It reads the
unrounded system chain, audits grid support and source sampling flags, and
compares paired climate calculations with the grid's fixed mass/radius and
the final fit's mean mass/radius. It also tests spectral interpolation and
F1500W integration resolution on representative atmospheres.

The latest seven-case check found at most 0.71 ppm F1500W and 1.26 ppm LRS
changes from updating mass/radius. All cases converged. The existing grid is
retained; these tests support a small-error approximation, not exact invariance.
No inference result is generated by this assessment.
